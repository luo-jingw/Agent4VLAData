# MimicGen: A Data Generation System for Scalable Robot Learning using Human Demonstrations
## 基本信息
- paper_id: paper_024
- 年份: 2023（arXiv v1，2023-10-26）
- 作者: Ajay Mandlekar, Soroush Nasiriany*, Bowen Wen*, Iretiayo Akinola, Yashraj Narang, Linxi Fan, Yuke Zhu, Dieter Fox（*同等贡献；NVIDIA、UT Austin）
- 来源: arXiv:2310.17596（预印本）
## 研究问题
人类示范收集昂贵，但数据中大量是"同一操纵技能在不同场景的重复"；如何把少量人类示范自动改造到新场景，生成大规模多样化数据用于模仿学习。MimicGen 用 ~200 条人类示范生成 50K+ 演示（18 任务、2 仿真器、1 真实机器人）。
## 方法
- 轨迹级增强机制：把源示范按对象中心子任务分割为 segments（Sec 4.1，子任务边界靠任务度量自动检测）；对新场景，每个子任务选一条源 segment，用新场景对象位姿做齐次变换（保持末端执行器目标位姿与对象坐标系相对位姿不变，Sec 4.2），段首加线性插值段连接当前末端位姿，控制器执行。
- 验证方式：不是模拟 rollout，而是真实执行（开环重放）后做任务成功检查（task success check），只保留成功轨迹，直至凑满 1000 条成功演示；数据生成率 = 成功轨迹数/总尝试数（Sec 3、Sec 4.2、Appendix P）。
- 失败处置：失败尝试丢弃、重新采样场景再试；失败原因（FAQ Q8）：线性插值段无几何感知导致碰撞、变换不考虑臂运动学使段起点难达、部分源段控制器难跟踪。
- 与事件/接触段关系：子任务分割（如 grasp/insert 段）即事件级切分；接触丰富任务（Square 插孔、Threading 穿线、Factory 装配 1mm/4mm 公差）靠对象位姿变换推广，不单独建模接触。
- 假设：delta-pose 动作空间；已知对象中心子任务序列；数据生成时每个子任务开始可观测对象位姿（策略部署时不需要）。
## 关键发现
- 10 源演示→1000 生成演示，成功率大涨：Square 11.3%→90.7%，Threading 19.3%→98.0%，Three Piece Assembly 1.3%→82.0%；D1 分布 42%–99%（Fig. 4）。
- 200 生成演示 vs 200 人类演示训练效果相当（MimicGen 只用 10 条源演示）；200→1000 提升大，1000→5000 边际递减。
- 生成率与训练后性能不必然相关：Factory Gear Assembly D1 生成率 8.2% 但 agent 76.0%；Object Cleanup D0 生成率 29.5%→agent 82.0%（Sec 6.3）。
- 跨臂：Square D0 生成率 38%–74%，4 臂策略性能 80%–91% 相似；真机 Stack 生成率 82.3%（243 次尝试）、Coffee 52.1%（192 次尝试），训练后 agent 成功率 Stack 36%、Coffee 14%（50 次评测）。
- 安全相关：只按任务成功过滤→数据集有偏（Square D2 覆盖 66.4%、Three Piece Assembly D1 43.5%，Appendix R）；线性插值不保证无碰撞（Sec 7/Appendix D.5）；真机为硬件安全把插值步从 5 增至 50，但更长插值段对策略学习有害（Sec 6.4、Appendix H）。

## 不确定项
- "增强轨迹的安全性"未定义：验证只检查任务成功，不检查机器人-环境碰撞、接触力或安全约束；执行前无模拟预验证（开环重放+事后成功检查）。
- 失败尝试对场景的影响（物体被打乱后的重置成本、真机安全事件）未讨论。
- 接触丰富子任务在变换后的接触保真度未单独分析；子任务边界自动检测细节在 Appendix K（本抽取未核对其内容）。
- 真机 36%/14% 与仿真差距归因于插值步数（Appendix H），但未与生成率、位姿估计误差等隔离。
- 增强轨迹与"事件/接触段"的显式对应关系（哪类段变换后安全、哪类不安全）文中未给出。
