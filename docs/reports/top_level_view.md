## 1 核心思路：多模态对齐（当前主轴）

- view / language / action 三模态在 pretrained 空间中做**对齐**；
- 用 vision + instruction 预测 action 序列——action 序列当作一种模态；
- 增强 = 在**对齐约束**下重构/强化 action 序列（簇是举例，不一定显式）；目标是
  数据效率 + 执行效率（embodied efficiency）。
