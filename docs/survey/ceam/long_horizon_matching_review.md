# 长期匹配与轨迹偏好调研

核对日期：2026-10-02。范围为八篇一手论文的机制、假设及当前 CEAM 的输入与标签接口。
本文记录文献事实、代码事实及其直接边界；尚未实施的验证方案在 `opportunities.md` 的 OPT-013。

## 结论与证据边界

动作表征与任务查询的组合可以具有长期价值语义，但这种语义来自明确的训练目标、数据分布和
后续策略。它不会由点积、余弦或非坍缩约束自动产生。任务无关的编码接口与后续策略无关的
长期后果是不同要求；现有相关方法明确处理了后者的依赖。

轨迹整体更快不要求每个动作更快。短片段可以通过改善终点处的后续机会而有价值；完整轨迹的
质量比较与局部动作的贡献也不是同一个标签。当前偏好实验已经使用首次成功的总时间，仍受
固定原示教后续、候选覆盖和可观测信息限制。

CEAM 的 52.79% → 61.49% → 69.98% 留出偏好排序结果支持反馈学习的可用性，尚未隔离双表征
相对直接打分器的优势，也未验证新的完整策略或多任务迁移。原始实验细节见
[偏好反馈结果](../../../synthesis/ceam/archive/docs/preference_feedback_results.md)。

## 一手来源与对应机制

| 来源与核对位置 | 已核对机制 | 与 CEAM 的边界 |
|---|---|---|
| [Successor Features，2017](https://proceedings.neurips.cc/paper/2017/file/350db081a661525235354dd3e19b8c05-Paper.pdf)，§3–4、式 2–3 | 给定共享特征和线性奖励权重，固定策略的长期价值分解为后继特征与任务权重的内积；GPI 比较多种已有策略 | 后继特征带策略上标；线性任务族和策略集合决定复用范围，语言查询不由该分解自动得到 |
| [Forward-Backward，2021](https://proceedings.neurips.cc/paper/2021/file/003dd617c12d444ff9c80f717c3fa982-Paper.pdf)，Definition 1、Theorem 2、§4 | 用 F(s,a,z) 与 B(s′,a′) 分解后继测度，以奖励对应的 z 提取策略 | F 显式依赖控制后续策略的 z；它不能直接作为严格只输入当前状态和动作的 r 的等价实现。精确结论要求相应表示条件成立 |
| [Contrastive RL，2022，v2](https://arxiv.org/html/2206.07568v2)，§4.1–4.3、Lemma 4.1 | 对当前状态动作和采样未来状态做对比学习，理想判别分数对应折扣未来访问密度的对数比，可用于目标条件动作排序 | 未来目标是状态；分数依赖正负采样分布及数据中的后续行为。其 Lemma 特别区分混合行为与指定目标条件策略 |
| [One-Step FB，2026，v2](https://arxiv.org/html/2602.11399v2)，§3–4、式 7、§6 | 分析 FB 的表示秩与优化限制，改为学习固定行为策略的后继测度，Fβ(s,a) 不输入 z，然后进行一次策略改进 | 更接近任务无关动作侧的接口，但预测的是行为策略的长期后果；一次改进不保证全局最优。该来源为预印本，本文不外推其基准性能 |
| [Models of human preference，2022/2023，v3](https://arxiv.org/html/2206.02231v3)，§2.2、式 3–5 | regret 偏好比较动作损失的长期机会；确定性片段的表达同时包含片段回报与终点价值 | 需要对应的偏好生成假设。CEAM 的测量 Pareto 偏好不自动等于论文的最优 regret 标签 |
| [Contrastive Preference Learning，2024，v3](https://arxiv.org/html/2310.13639v3)，§2–3 | 在 regret 偏好与最大熵假设下，将最优优势转成策略对数概率，直接用偏好训练策略 | 优化对象是策略概率，不是任意 embedding match；当前余弦排序损失不因此获得 CPL 的理论结论 |
| [Preference Transformer，2023，v1](https://arxiv.org/html/2303.00957v1)，§4、式 3 | 用上下文相关奖励和片段相关权重表达轨迹偏好，不要求每一步同等贡献 | 片段评估可使用已发生的序列；在线动作输入仍须满足时间可用性。注意力权重本身不是反事实归因证据 |
| [TD-JEPA，2025，v1](https://arxiv.org/html/2510.00739v1)，§3–4 | 从无奖励转移学习状态/任务编码和策略条件的多步潜在预测；用 TD 连接较远后果 | 预测器仍有策略条件 z；这里的任务编码器编码状态，并非语言指令编码器。非坍缩理论针对理想化条件，不能直接迁移为 CEAM 保证 |

TD-JEPA 此处特指 Bagatella 等的 arXiv:2510.00739；与使用同一简称的 Temporal-Distance JEPA
arXiv:2607.25337 是不同论文。八篇来源的相关正文与公式已经核对；没有复现实验或进行穷尽的新颖性判断。

## 三个容易混淆的等价关系

### 任务无关与策略依赖

在 Successor Features 的设定下，奖励记为 R，避免与 CEAM 的动作表征 r 混淆：

\[
R_\ell(s,a,s')=\phi(s,a,s')^\top w_\ell,
\qquad
Q^\mu_\ell(s,a)=\psi^\mu(s,a)^\top w_\ell.
\]

ψ 可复用于不同奖励，但其预测的未来特征仍取决于 μ。改变后续策略会改变 ψ 的目标。
即使状态完全可观测，给定当前动作也只确定下一步的转移分布；更远的分布仍需要后续动作规则。
这是论文的固定策略分解；它没有证明一个低维、固定的任务无关向量配上线性查询，就能精确
表示任意任务的最优策略价值。FB 通过策略条件 z 处理这一依赖；one-step FB 则固定行为策略。

这也不构成对 CEAM 的否定：足够有信息的 r 和更一般的查询/匹配仍可表示复杂任务关系。
现有论文的精确低秩后继测度要求，比 CEAM 的有限候选可分性要求更强，两者不能互作否定证据。

### 对比分数与价值

Contrastive RL 的理想 NCE 判别器满足：

\[
f^*(s,a,g)=\log\frac{p^\mu_\gamma(g\mid s,a)}{p(g)}.
\]

其中 μ 表示论文定义的数据后续行为，γ 控制未来采样，p(g) 来自负样本边缘分布。
固定 g 时，这种理想分数可排序相应的未来访问密度；它不是未经变换的成功概率。
当前 CEAM 的成功 BCE 与候选 Pareto 排序没有实现该采样目标，其 cos 分数没有该密度比解释。
跨不同目标直接比较分数，还涉及不同的 p(g)。

### 整段偏好与局部贡献

regret 论文在确定性、无折扣片段设定下给出：

\[
\mathrm{regret}(\sigma)
=V^*(s_0)-\left[\sum_{t\in\sigma}R_t+V^*(s_H)\right].
\]

片段末尾能接上怎样的未来，进入了比较。对同起点、终止状态结尾的完整确定性轨迹，终点价值
为零，regret 与回报排序一致；对未完成任务的短片段，终点价值不能省略。
因此，完整轨迹反馈不能直接替代每一步的速度标签。上述恒等式的期望形式、随机性处理与
最优价值假设见原论文；当前实验没有估计 V*，不能称为最优优势学习。

## 当前实现的输入与标签审计

| 项目 | 代码事实 | 已知解释边界 |
|---|---|---|
| 观测 | 当前双相机图像，经冻结 DINO/PCA/R6；proprio 为七个关节位置和两个夹爪位置 | 没有显式速度、控制器状态或历史输入。现有测量不能判断这些缺失分别导致多少误差 |
| 动作 | 每个候选为十步、每步七维；r 不输入任务指令 | 这是动作块，不能用单步动作维数判断完整策略搜索难度 |
| 后续 | 替换一个动作块，随后逐项执行原示教剩余命令 | 标签描述与该源轨迹后续的组合效果；改变后续的排序敏感性未测量 |
| 截止 | 首次成功或源示教动作序列结束 | 未成功是该预算内的结果，不等于任何后续都无法完成任务；源 episode/anchor 未作为模型输入 |
| 可行性 | `BranchValidity` 以公共前缀的累计结果初始化，然后累加候选及后续执行 | 前缀已经违规时，后面的候选都无法改变完整路径标签。这是示教验收信息，不能全部归因于当前动作 |
| 兼容性目标 | `success & feasible` | 任务失败、物理检查失败、公共前缀失败被合并；单独预测这些因素的效果尚未比较 |
| 偏好目标 | 成功且通过检查的候选中，总时间和 EEF 平移路径的 Pareto 比较 | 局部慢动作被允许；更快但略长的轨迹可能不可比，抖动不在这个偏好目标中 |
| 存储 | 每个 bank 保存起点快照及全程汇总指标 | 没有单独保存 prefix/candidate/continuation 的可行性汇总，也没有完整分支观测序列；无法仅靠现有 bank 无损分离各段违规 |

对应代码：`ceam/sim/libero_task_env.py` 的 SimObservation；
`ceam/preference/preference_encoding.py`；`preference_collection.py` 的 `_replay` 和 `run_task`；
`branch_validity.py`；`preference_bank.py`；`preference_data.py`。

任务成功与完整物理可行性必须继续分别报告。分离局部学习标签不等于放宽完整示教的验收标准。
当前数据不足以判定兼容性较差的主因是输入不足、覆盖不足、表示能力还是共享损失相互影响。

既有 `ceam/sim/continuation_branch_executor.py` 属于聚焦实验：固定八个候选，候选块始终执行满
十步，再接原 π。它的 `executed_steps` 在候选中途成功时仍计入整块，且不记录分段可行性。
因此，它可以提供闭环策略调用的参考，不能直接替换偏好采集器并声称保留首次成功时间的语义。

## 结构与验证边界

- 当前严格任务无关的是 r 的输入接口。任务条件梯度仍会影响其学习结果；没有实验证明它覆盖了
  所有未来任务需要的区别。
- 固定 r 与适配 r 的对照没有控制新增原始动作输入和模型容量，也没有直接打分器对照。
  当前数值不能独立确认“高维双表征结构”是偏好收益的来源。
- 打乱指令只能检查模型是否依赖指令；正确的语义检验还需要同一场景下可验证的不同任务结果。
- 任务条件继续执行策略 μ(a|o,ℓ) 是策略族。固定其 checkpoint 不等于使用对所有任务相同的
  无任务行为策略，不能据此直接套用固定行为后继表征的解释。
- 累加预测长期价值会重复计入重叠的未来。若 match 被赋予 Q 的语义，逐步 match 求和没有自动
  等同于轨迹回报；原先的正累计 match 条件仍只是可选约束。
- RL 文献已有奖励无关预训练、多任务表征和内积价值分解。当前证据不支持以“RL 不能多任务”
  或“RL 必须硬编码逐步成功语义”作为 CEAM 的区别；新颖性与优势需要相同预算的具体比较。
