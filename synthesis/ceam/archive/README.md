# CEAM 原始研究档案

本目录保存 CEAM 提交 `713f20f` 中的结果、分析、实现诊断、实验计划和问题记录。
不同阶段有各自的协议和历史决策，不能把早期固定参数或已完成计划当作当前框架要求。
当前总览见 [研究入口](../../../docs/reports/ceam/README.md)，当前研究结构见
[条件效果与动作编辑](../../../idea/ceam/README.md)。

## 目录

| 目录或文件 | 内容 |
|---|---|
| `docs/` | 早期状态几何、闭环、数据规模、交互表征、LIBERO-90、偏好、teacher 与残差的详细报告 |
| `plans/` | 各轮实验接口和执行阶段；计划状态与完成证据分开 |
| [问题快照](issues.md) | 历史与当前问题、观察、假设和后续实验 |
| [机会快照](opportunities.md) | 尚未纳入执行的研究方向 |
| [计划快照](plan.md) | 残差诊断完成后的 CEAM 状态，当前没有执行中的阶段 |

原始报告中的 `ceam/`、`configs/`、`scripts/`、`outputs/`、`tmp/` 是 CEAM 实现及其本地产物的定位符，
不指向 Agent4VLAData 同名路径。该实现的完整代码、数据和权重未包含在本档案中。
显式 Markdown 文档链接已经重定位；少量早期报告保留的原始运行名称用于对应研究历史。

机器专用根目录与主机名在公开副本中使用占位符；命令用于说明原始协议，不能作为此仓库的直接运行入口。
文本中的历史结论保留其当时范围，英文测量记录保留原文，中文总览给出跨阶段解释。

文件原文 SHA256 与公开副本 SHA256 见 [来源清单](../source_manifest.json)。源 commit 属于独立 CEAM
仓库，不属于 Agent4VLAData 的 Git 历史；导入 commit 的父提交来自 Agent4VLAData main。
