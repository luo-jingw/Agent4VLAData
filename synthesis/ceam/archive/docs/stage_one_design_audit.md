## 当前实际生效的损失与权重

`StageOneObjective` 对 6 项求加权和，权重均为 1。D = ‖z_T − z₀‖² + ε（ε = 1e-6，带梯度），z = Uᵀψ，sg 为停止梯度。

| 项 | 实现 | 权重 | 是否生效 |
|---|---|---|---|
| SIGReg | 均匀帧 ψ 在 256 个随机方向上的一维投影 vs 𝒩(0, 1)（Epps–Pulley） | 1 | 是 |
| 路径 | ‖(I − nnᵀ)(z_t − Uᵀsg[ψ₀])‖² / D，n = sg[(z_T − z₀)/√D]，只约束垂直分量 | 1 | 是 |
| 目标 | ‖Uᵀĝ − Uᵀsg[ψ_T]‖² / D | 1 | 是 |
| 终点等价 | ‖z_T − z′_T‖² / D，z′_T 为同任务另一条示范的终点 | 1 | **是，仍在生效** |
| 改写一致 | (1 − ‖U_aᵀU_b‖²_F / 8) + (1 − cos(q_a, q_b))，两项相加 | 1 | 是 |
| 指令对比 | 对 z = ψ(o_{t+k}) − ψ(o_t)（k 随机）：logsumexp 于 s·cos(z, q) 的本任务项与负样本任务项之差，s 可学习 | 1 | 是 |

## 逐项对照

标记：保留 = 与设计一致；修改 = 保留意图但形式变了；删除 = 设计中有、实现中无；新增 = 设计中无。

| 设计项 | 原始设计 | 当前实现 | 标记 | 变化来源 |
|---|---|---|---|---|
| C1 静止基线 | ψ(o) = E(o, ∅)；Δ = E(o, a) − E(o, ∅)；∅ 为学习的 token 或真实零动作 | ψ 由独立的状态主干给出，不接动作；E(o, a) = ψ + Δ；静止的效果按定义为 0，不学习 | 修改 | 用户修订"拆分编码器与预测器"；数据集去除了零动作帧，后在数据 A 中补入静止转移供 Δ 训练 |
| C2 固定步长 | 所有动作完整位移模长为 c | 无 | 删除 | 用户修订"固定步长整体去掉" |
| C3 全局 SIGReg | 聚合分布 ≈ 𝒩(0, σ²I) | 作用于 ψ（不含指令），权重 1 | 保留 | 用户修订"SIGReg 施加在 ψ(o) 上" |
| C4 语言等价 | 状态依赖：l₁ ∼_o l₂ ⇒ 表征相同；加同场景不等价指令的负样本 | 查询侧的改写一致：子空间项 + 方向项；查询仅依赖文本，不依赖状态；没有单独的负样本项，"不等价指令"由指令对比项的负样本任务承担 | 修改 | 用户修订"C4 施加在查询侧"；阶段一定版取仅文本查询 |
| C5 条件线性路径 | ψ_t = (1 − t/T)ψ₀ + (t/T)g，g = ψ(o_T)，逐帧插值目标 | 只约束投影空间中的垂直分量，沿线位置不受约束 | 修改（沿线分量删除） | 用户修订：先"t/T 改为 s_t"，再"C5 只约束直线，不约束匀速"，再"C5 在投影空间施加"。用户现认定删除沿线分量是错误决定，正在恢复（第二计划 Phase 17） |
| 防平凡解项 | 方差下限或时间对比，后改为弱单调 hinge | 无 | 删除 | 用户决定"hinge 和 margin 没必要加" |
| 失败数据 margin | 失败终态在投影空间中与 ĝ 保持 margin | 无 | 删除 | 同上。之后另行提出 OPT-008（失败 rollout 作负样本），已批准后又暂缓 |

## 结论

- 生效中的 6 项里，SIGReg、终点等价是原设计（及其修订）的原样实现。终点等价目前仍在生效。
- 目标项与路径项保留了意图，但路径项删去了 C5 的沿线分量。
- 改写一致、指令对比、方向头是后来的新增。
- 原设计中已删除的：固定步长、C5 的逐帧插值（沿线位置）、防平凡解项、失败 margin。其中逐帧插值由用户决定恢复（第二计划 Phase 17）。
