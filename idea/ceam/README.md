# 条件动作效果与示教编辑

截至 2026 年 10 月 4 日，这一研究包含条件动作双表征和离线动作编辑两个相关问题，以及冻结 teacher
辅助编辑的独立方向。目标是相对已有示教获得更好的动作或更好的训练数据，不要求达到全局最优。
[实验总览](../../docs/reports/ceam/README.md) 记录现有证据；本页中的候选机制尚不能视为已经验证的结论。

## 条件动作双表征

EEF 动作可以低维表达，但动作坐标本身不能说明它在当前情境中的用途。同一命令在自由运动、
接触、夹持或释放阶段可产生不同效果；不同命令也可能产生任务等价的效果。

| 对象 | 输入 | 职责 |
|---|---|---|
| r | 当前观测、机器人状态、候选动作或动作块 | 表示该候选产生的、下游选择需要区分的效果或关系；不读取任务指令 |
| q | 当前观测与任务指令 | 表示当前任务可接受的效果类别 |
| match | r 与 q | 比较同一起点下候选效果与任务需求的兼容程度 |
| sampler | 显式定义的采样条件 | 提供候选，可以来自 BC、检索、teacher、随机动作或学习式生成器 |

执行是“产生候选→比较→执行→获得新观测→重新比较”的过程。任务不变时，查询与可达效果仍可随观测变化。
框架不要求线性潜在路径、固定目标点、固定步长或分数单调增加，完整职责见 [框架定义](framework.md)。

同观测可分性是下游需求，不限制表征只能用相似观测训练。示教、失败、恢复、探索和其他 episode
都可以提供交互知识。预测式联合嵌入、对比、掩码目标和 SIGReg 是候选方法；不指定唯一的 JEPA 实现。

“成功轨迹累计 match 为正”是曾讨论的弱辅助约束，允许局部负分，也允许失败轨迹累计为正。
它本身不构成成功判据。余弦、点积和距离只是比较结构，改变形式不会自动提供速度或最优性监督。

## 离线动作编辑

编辑器面对已有轨迹，可以读取其过去与未来上下文，然后输出某个时间区间的替换动作。
部署学生仍只能读取部署时可用的信息；完整未来只用于离线编辑，并不会自动解决学生的观测歧义。

| 编辑形式 | 目标 | 验证要求 |
|---|---|---|
| 几何和时间调整 | 减少无效路径、改善时间分配、降低抖动 | 控制器一致、必要接触和等待保留、真实物理耗时 |
| 按语义删除 | 去掉不必要的绕行或操作 | 必要任务效果和后续可执行条件仍满足 |
| 检索片段 | 复用其他 episode 中有用的局部行为 | 当前状态的可达性、夹持/接触阶段、边界衔接 |
| 低秩残差 | 小幅适配原动作或 donor 片段 | 原候选对照、幅度与预算对照、物理执行后的效果 |
| 多片段联合编辑 | 组合成更好的整段行为 | 不能仅凭各片段局部优于原始就认定整段更优 |

偏好针对成功完成任务的整段时间、EEF 路径与物理抖动。必要对齐、抓取稳定和准备动作可以局部更慢。
单纯成功不表示质量更高；单纯更快也可能增加抖动或损失成功。

已有实验主要是一个十步动作块的替换；最近的低秩是固定 DCT 时间基的低频扰动，尚未训练残差生成器。
语义操作删除、可变时长和多片段联合适配仍属于未完成方向。

## Teacher 与数据集条件化

这一分支的目标接口可以写成：

`G(teacher 权重, 数据集上下文, episode 与编辑时间区间) → 替换动作序列`。

数据集上下文可以是原始样本，也可以是保留相关信息的压缩形式。codebook、子空间和归一化是工程选项，
不是“所有更优动作必然落在示教流形内”的假设。直接改善蒸馏或微调也是独立的可选输出。

现有 pilot 只固定一个 π0.5 teacher，反演示教动作后在噪声坐标里做局部扰动，并测量数据方差校准。
它没有学习接收不同 teacher 权重的网络，没有压缩完整数据集，也没有证明容量压缩本身产生更优标签。
该 teacher checkpoint 使用图像与指令，不读取机器人状态；未来编辑器增加状态通路属于新增机制。

## 尚待检验的主张

- 共享交互学习能否在观测差异较大的 episode 之间迁移动作知识。
- 双表征分工是否带来数据效率、任务复用或泛化收益，超过同输入直接打分。
- 任务效果和片段边界条件能否支持可迁移的质量排序。
- teacher 与数据集条件化能否优于同预算直接动作编辑及未校准 teacher 编辑。
- 优化动作标签能否在匹配协议下稳定提高学生 SR、完成时间和运动质量。

上述问题与完整 RL 对照、多任务迁移均未得到肯定结论。[开放问题表](../../synthesis/ceam/open_questions.md)
列出已有证据和缺少的检验。
